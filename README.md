# Backend Mentoring

## 📖 About

This repository documents my journey towards becoming a professional Backend Developer.

The goal is not only to learn new technologies, but also to develop the habits, workflow and mindset required in a real software engineering environment.

Every exercise, project and note in this repository represents part of my learning process and serves as a record of my progress over time.

- Strengthen my Python programming skills.

## 📚 Learning Methodology

I follow a long-term learning plan based on consistency rather than intensity.

My current study routine consists of:

- **Monday to Friday:** 1–2 hours focused on learning a specific topic.
- **Weekends:** Building or improving a larger project to apply everything learned during the week.

The objective is to understand the reasoning behind the code instead of simply making it work.
